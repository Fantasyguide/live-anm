# Coding agent CLI 实施计划

> 用户已于 2026-11-02 确认“好，开干”。按已列明边界分工实施，主任务集中集成和验证；保留当前工作区中的前端改动，不自动安装、提交或发布。

**Goal:** 为 coding agent 提供 ANM 文件操作和可复用既有浏览器环境的 PNG/GIF 导出。

**Architecture:** Node CLI 复用既有格式／VM；独立浏览器页面公开小型渲染 API；可选适配器调用环境提供的 Playwright。文件结果经本机服务直接保存，agent 接收简短元数据。

**Tech Stack:** Node 22、ESM、内置 parseArgs/fs/http/module，现有 Vite/WebGL/gifenc；Playwright 由运行环境提供，不加入项目依赖。

**Spec:** [设计与调研](../specs/2026-11-02-agent-cli-design.md)。命令、参数默认值、JSON、输出路径及 API 以该文档为准；下文不重新定义。

## Global Constraints

- 保留当前未提交的前端改动，不混入其提交，不改变已有分页、布局、草稿、Sprite/GIF 功能。

- 新增测试仅覆盖列明的核心行为；最终集中运行已有检查，不为小修反复全量验证。

## Review Focus

| script.id 与全局序号不同，替换错脚本 | T1 多 entry、负 ID 测试 |

## 文件与依赖方向

| 文件 | 职责 |
| --- | --- |
| `bin/anm.mjs` | 轻量进程入口，仅调用 main 并设置 exitCode |
| `cli/main.js` | 命令分派、参数解析、stdout/stderr、统一结果和错误 |
| `cli/core.js` | 元数据、选中脚本 dump/replace、manager 执行与 JSON 投影 |
| `cli/render-server.js` | 指定 ANM、dist 静态页面、输出文件，纯 Node HTTP |
| `cli/browser-runner.js` | 按需装载外部 Playwright，创建并释放自己的浏览器／服务 |
| `web/agent.html`、`web/src/agent-api.js` | 无 Vue 编辑器的页面 API，Blob 结果保存与简短元数据 |
| `web/src/capture.js`、`web/src/frame-export.js` | GIF/PNG 共用读取裁剪；单帧 PNG 导出 |
| `web/src/gif-plan.js`、`gif-export.js` | 仅必要的 capture 复用接线，保留原导出接口 |
| `vite.config.js`、`package.json` | agent 构建入口、npm run anm 别名，不引入依赖 |
| `tests/cli-core.test.js`、`cli.test.js`、`cli-render-server.test.js`、`cli-browser-runner.test.js` | 直接调用真实生产逻辑或 CLI 子进程 |
| `scripts/smoke-agent-render.mjs`、`docs/agent-cli.md` | 可选真实渲染样例和 agent 使用说明 |

不建立服务容器、插件注册表或通用存储层。若某个文件实现过大，再按已经出现的责任拆分，不预建目录框架。

- [x] 测试解析输出后的目标 ID 仍为42、指令为403/3及参数128；未编辑指令、sprite 元数据及 thtxRaw 保留。预期值使用明确字面值或输入数据，不通过文本重组生成。
- [x] 增加一条无效文本用例，返回行号且 bytes=null；以及越界 script 序号、s16 time/opcode 范围检查。只在替换入口校验编码所需字段，不新增全文件校验／修复体系。
- [x] 实现累计全局索引与选中替换；原 parsed entries 复制目标记录，未编辑指令不经过 assembler。inspect/dump 不解码贴图。

## T2：命令入口、文件 I/O 与 VM 输出

接口：`main(argv,{cwd,stdout,stderr}) -> Promise<number>`；`runScript(bytes,index,{steps,position}) -> snapshot`。snapshot 输出根状态和活跃 VM 白名单，保留原始数值；根被回收后仍可见。

- [x] 编写少量真实 CLI 子进程测试：`inspect --json` 可直接 JSON.parse；dump 的 thanm/raw 与目标 script 对应；replace 失败不创建输出，默认不覆盖现有输出，--force 可覆盖输出；输入路径保持不变。
- [x] 实现 Node parseArgs 严格参数分派、--help、JSON envelope、退出码0/1/2、stderr 日志。bin 仅调用 main；package scripts 增加 anm 别名。main 仅在相应命令调用时动态加载浏览器／服务模块，核心命令不引入网页构建依赖。
- [x] 添加 run 的 steps=0/1、delete 后 root 状态测试，使用真实 manager 和合成脚本；不 stringify 循环对象。其余 VM 指令依赖现有覆盖，不重复一套模拟器。
- [x] 实现 run；错误停止该次命令，注明已完成步数，不做状态回滚。将最终 drawList skipped 和文件内未注册 opcode 转成明确的 warnings，不声称未执行分支已被执行。
- [x] 运行 `node --test tests/cli-core.test.js tests/cli.test.js`。在无项目依赖的临时源码副本中做一次核心命令 smoke，不复制 node_modules、不改主工作区依赖。

- [x] 修改现有 Vite 多入口构建，生成 dist/agent.html；不改默认 Pages base/部署工作流。页面资产与服务的 --base 保持一致。

## T4：agent 自有工具使用的本机服务

接口：`startRenderServer({inputPath,outDir,port=0,force=false,base='/live-anm/'}) -> Promise<{url,outDir,close}>`。close 是本次 listener 的正常生命周期，不涉及用户浏览器。

- [x] 实现前先写真实 HTTP 临时目录测试：只返回指定输入字节和构建静态资源；未定义路由404；同源 artifact POST 写入指定目录，返回绝对路径和字节数；默认已有文件不覆盖，--force 可覆盖。
- [x] 覆盖一条包含路径分隔符的 artifact 名被拒绝的测试，不加入目录扫描、账户或凭证系统。
- [x] 实现 Node HTTP；仅127.0.0.1、无后台守护；GET input/static、POST artifact。限定输出 basename 和类型，校验 Origin；结果直接文件写入，不建任务表、队列或重试协议。
- [x] 实现 serve 命令：成功启动输出一次 ready JSON，含 url/outDir；缺少 agent 构建产物给出明确提示，不自动安装／构建。Ctrl+C 关闭当前服务。
- [x] 运行 `node --test tests/cli-render-server.test.js`；不启动浏览器。测试辅助保持在本文件中且简短，不引入大型 HTTP harness。

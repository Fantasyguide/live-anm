# GIF 导出与可调范围

用户已确认 gifenc 浏览器编码方案，并要求可调导出区域。沿用 Vue、Vite 与现有播放器；编码器只在导出时加载，引擎运行时保持零依赖。

范围：选中的已应用脚本，从第 0 帧重播，包含脚本生成的子／根 VM。使用当前画布及生成位置，独立画布渲染，黑底；默认 3 秒、20fps、循环。提供 10/20/30fps、0.1–30 秒、循环开关、进度和取消。

裁剪：画布左上角为原点的整数 X/Y/宽/高，必须位于画布内；输出像素尺寸等于裁剪宽高。默认整张画布，提供恢复整幅按钮，并在预览上显示区域边框。只裁剪，不改变动画坐标或加入拖拽选框。

界面：在已有右侧预览下增加可折叠 GIF 面板，继续使用现有颜色、字号和数字输入。无独立设计画布、布局重做或新 UI 依赖。

- [x] gif-plan.js：裁剪参数校验、60Hz 采样帧、GIF 百分之一秒延时、像素行翻转；添加 4 条关键行为测试。
- [x] gif-export.js：独立播放器逐帧重播、读取裁剪区域、gifenc 编码、进度与取消，结束释放自己的 GL 上下文。
- [x] GifExport.vue、Stage.vue、App.vue：导出设置、区域边框、下载入口；保留手动应用语义。
- [x] 安装 gifenc 1.0.3（无传递依赖），更新 README。npm test：375 通过、1 跳过（缺少 thanm）；npm run build、git diff --check 通过。构建将 gifenc 分为按需加载的独立文件。

只读审阅未发现重要问题。编码样例使用生产采样计划、像素翻转和实际 gifenc API，并经 Pillow 独立解码确认 2×2、3 帧、红上蓝下、30/40/30ms 延时和循环标记。样例文件在 <temporary-gif-file>；这不代替真实浏览器中的 ANM 渲染与导出验证。本轮未执行浏览器页面交互或真实 WebGL 导出。

# live-anm

**东方 ANM v8 播放器** —— 用 JavaScript + WebGL 复刻 TH16《鬼形兽》的 ANM 子系统，
在浏览器里直接放 `.anm` 动画脚本。

零依赖的纯 ESM，**304 个测试**，不需要构建工具就能跑。

## 这是什么

`.anm` 是东方 Project 从 TH06 起使用的精灵动画格式：一个文件里装着贴图、精灵切片表，
以及一套**字节码脚本**——每个精灵由一台小型虚拟机驱动，逐帧执行 `pos` / `rotate` /
`scaleTime` / `createChild` 这样的指令。游戏里几乎所有会动的东西（子弹、敌人、UI、
符卡背景、菜单）都是 ANM 脚本画出来的。

本项目把那台虚拟机和它的渲染管线整个搬到了浏览器里：

| 层 | 内容 | 状态 |
| --- | --- | --- |
| 格式层 | `.anm` v8 解析、THTX 贴图解码（format 1/3/5/7 → RGBA8） | ✅ |
| 层 A · VM | **135 / 135 条 opcode**、36 个脚本变量、12 组帧尾插值器、父子 VM 树 | ✅ |
| 层 B · 渲染 | sprite 四边形几何、帧尾几何三族、D3D9 → WebGL 状态映射 | 🟡 部分 |
| 宿主 | VM 列表、layer 排序、子树回收、全局序号解析 | ✅ |
| Web | 拖进 `.anm` 就能播 | 见 [`web/`](web/) |

**层 B 还缺**：`draw_vm` 的 mode 4 / 8 / 15 等路径，以及 mode 24/25 的 3D 变换接入。
矩形、多边形、阴影、边框和线段的无贴图路径已接通，见 [一手研究结论](docs/anm-primitives.md)。详见 `OVERVIEW.md`。

默认宿主已接入 TH16 原生 PRNG 的两条独立流，支持随机指令及随机变量；重建后从固定初值重放。
算法依据与宿主范围见 [ANM 随机数](docs/anm-random.md)。

## 不含任何版权数据

**本仓库不包含、也不会包含任何 ZUN 的游戏数据**——没有 `.anm` 文件、没有贴图、没有一个字节。
网页版靠**你自己上传**手里的文件；测试夹具全部是自造的合成数据。

## 跑起来

```bash
npm test          # 312 个测试，**不需要装任何依赖**，裸 node 就能跑
```

网页版是标准的 Vite + Vue 3 SFC 工程：

```bash
npm ci
npm run dev       # 开发服务器
npm run build     # → dist/（GitHub Pages 发的就是它）
npm run preview   # 预览打包产物
```

编辑文字会立即保留在当前文档中，切换 script 不会丢失未应用的内容。
桌面布局可拖拽编辑区与右侧预览区之间的分隔线调整宽度占比；双击可恢复默认，方向键也可调整。
Script 和 Sprite 列表支持筛选、分页及页码跳转，默认每页 20 项，可切换为 10 或 50 项。
切换到 Sprite 后，中间区域会显示选中切片和原贴图的位置框，透明部分用棋盘格表示。
修改 x/y/w/h 会立即更新静态图片，无需运行脚本；“应用到动画预览”会重建播放器，之后需重新播放脚本。
「应用并预览」更新播放版本；「导出 .anm」（Ctrl+S / ⌘S）保存最新编辑，有汇编错误时会阻止导出。
未导出的修改会显示提示，打开其他文件或离开页面前会提醒。
编辑停顿 500ms 后会在当前浏览器保存最近一份草稿，刷新后可选择恢复或丢弃。
草稿保留原文、注释、Sprite 修改和贴图，有语法错误也能保存；保存失败会提示，仍可导出 `.anm`。
`.anm` 保存编译后的指令，不保存源码注释和标签名称。

预览下方的「导出 GIF」可以把当前选中的已应用脚本从头导出，默认 3 秒、20fps、黑底循环。
展开面板后，可设置时长、帧率及画布左上角起算的 X/Y/宽/高，预览上的虚线框表示导出区域；
输出尺寸就是范围的宽高，「整张画布」可重置范围。导出包含脚本生成的子动画，使用当前生成位置，
独立重播并显示进度，可随时取消；不会录制已在预览里运行的多个 VM 或手动中断操作。
GIF 编码使用按需加载的 `gifenc`，全程在本机浏览器处理。

`npm test` 与构建**是两条独立的路**：运行时（`src/`）是零依赖的纯 ESM，测试直接
`node --test`；Vue / Vite / gifenc 是网页壳子的依赖，不装也能跑测试、也能把 `src/` 拿去用。

Coding agent 可从仓库内执行 `node bin/anm.mjs inspect input.anm --json`，
检查文件、导出或替换单个脚本、运行 VM；PNG/GIF/Sprite 导出可复用环境已有的 Playwright 和浏览器，
也可通过 `serve` 交给 agent 自己的浏览器工具。参数和示例见 [CLI 使用说明](docs/agent-cli.md)。

打包产物里还会附一份**未打包的 `dist/src/`**（`scripts/postbuild.mjs` 拷的）——
这个项目的卖点之一是「引擎知识的可执行形式」，保留可直接 import 的 ESM 方便别人
`import('https://fantasyguide.github.io/live-anm/src/vm/core.js')` 拿去用。

**浏览器自测**：`/selftest.html` 当场合成一个 `.anm`（不挑现成夹具——第一版挑了个
只有 1 个 sprite 却 `sprite(3)` 的，越界被跳过、画布全黑，看着像管线断了），跑完整管线
并断言 `readPixels` 读回**正好 256 个品红像素**，数目对得上才说明几何也对。

Node 里那 320 个测试用的是 mock GL，**真实 GL 的行为只有浏览器能验**。

## 保真度

目标是「**能跑、看着像**」而不是逐像素等同真机。每条实现都对着 TH16 v1.00a
（`th16.exe`，imagebase `0x400000`）的一手反汇编写，代码注释里带着具体地址与文档章节号，
例如：

```js
// 09 §3.2：`scale.y` = 环的中心半径、`scale.x` = 环宽
// （`th16:0x4636e7`–`th16:0x46370a`）
```

这些 `09 §3.2` 形式的引用指向一份**独立的逆向知识库**（`engine/anm/th16/01-format.md` …
`10-sprite-geometry.md`），它不在本仓库里。引用保留成文本而不是链接，是因为那份知识库
目前不公开；但**每条引用都写明了文档号 + 节号 + 机器码地址**，足以让人自行复核。

### 「在指定位置播放」

ANM 脚本**自己不决定绝对位置**。`final_pos = pos + pos_2 + entity_pos`
（`th16:0x406c40`），其中 **`entity_pos`（`+0x5e0`）是「宿主实体坐标」**——真机里敌人 /
子弹 / 自机对象把自己的位置写进这个字段，脚本只管相对动画。`AnmVm::wipe` 专门**保留**
这块不清（02 §3.3），正因为它属于宿主而不属于脚本。

所以「把这段脚本放到某个位置播」的引擎正解是设 `entity_pos`，而不是去改 `vm.pos`
（那是脚本自己会动画的量）：

```js
manager.spawn(scriptIndex, { entityPos: { x: 320, y: 240, z: 0 } });
```

网页版把它做成了「位置」输入框，默认放在画布正中——不给的话是 (0, 0)，也就是画布左上角，
多数脚本会有一半在画外。那不是 bug，是「宿主还没写过这个字段」的忠实状态。

**有意偏离真机的地方**一律显式记在代码与 `OVERVIEW.md` 里，不假装没有。例如：
贴图不做 `entry.format` 的降位转换（比真机更准）、`sprite(-1)` 不加载 `ascii.anm` 的
系统贴图（真机会换，这里按「不使用图像」处理）。

## 跟社区实现的两处已知分歧

- **RGB565 不抄 thanm**。thanm `image.c` 的蓝通道位运算有 bug（三项都写成 `<< 16`，掩码
  却在 bit18/17/16 ⇒ 前两项恒为 0），**蓝通道永远到不了 255**，纯白解出 `(255,255,249)`；
  65536 个取值里 99.6% 与 GPU 不同。真机把 RGB565 交给 D3D9 纹理、扩位由 GPU 做，
  所以这里走标准高位复制。`{ rgb565: 'thanm' }` 可切回去对拍。
- **blend mode 4 不是 Screen**。thpages 记作 `Screen? (S + D − SD)`，实际是 `S + D − 2SD`
  ——白叠白给**黑**而不是白。详见 `src/render/D3D9-MAPPING.md` §2.1。

## 目录

```
src/format/   anm-v8.js（.anm 解析） thtx.js（贴图解码）
```
